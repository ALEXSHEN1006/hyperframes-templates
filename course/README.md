# 课件讲解版模板（course）

横屏 1920×1080 · 40 秒 · 结构：标题页 → 五步讲解（步骤卡依次点亮）→ 要点收束页
风格：专业克制，适合投屏讲课。样片课题：《AI 短剧制作五步流程》。

## 换内容改哪里（只改 index.html）

文案全部集中在 index.html 里三个标了「文案区」的段落，直接改文字即可：

1. **标题页**（搜「文案区 1/3」）：课题名（h1）、副标题、顶部小字（kicker，课程名）。
2. **分步讲解**（搜「文案区 2/3」）：五张步骤卡的序号下标题（.name）与说明（.desc）。
   - 说明文字保持两行以内（每行约 13 字），卡高 500px 已留足，不会溢出。
   - 步骤固定 5 个；若改步数，需同步改底部 script 里的 `lightAt` 数组和总时长（见下）。
3. **收束页**（搜「文案区 3/3」）：三个要点块文字 + 落款。

## 改时长改哪里

- 总时长：`#root` 的 `data-duration`（默认 40）与第 3 幕 section 的 `data-start` 保持一致逻辑：标题 6s + 讲解 28s + 收束 6s。
- 步骤点亮节奏：script 里 `lightAt = [6.8, 12.3, 17.8, 23.3, 28.8]`，五步等距；改讲解段长度时等比缩放这组数。
- 进度条时长：`#track-fill` 的 duration（默认 26.6）≈ 讲解段长度 − 1.4。

## 改配色改哪里

`<style>` 顶部「品牌基线」:root 变量，三套模板共用同一套；只改本套就只动本文件。

## 渲染

```bash
TMPDIR=~/.tmp-hf npm run check    # 先过官方检查
TMPDIR=~/.tmp-hf npm run render   # 出片到 renders/
```

依赖全本地（assets/gsap.min.js），字体走系统 Noto Sans CJK SC 的 @font-face local()，不要改回 CDN。
